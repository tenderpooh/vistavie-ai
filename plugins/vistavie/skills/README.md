# 사내 스킬

스킬마다 이 폴더 아래에 `<스킬 이름>/SKILL.md`를 만듭니다. 이름은 영문 소문자와 하이픈으로 씁니다.

```text
skills/
└── <스킬 이름>/
    ├── SKILL.md
    ├── references/   # 필요한 참고 문서가 있을 때
    └── scripts/      # 실행할 보조 코드가 있을 때
```

`SKILL.md`의 YAML 머리말에는 `name`과 `description`을 씁니다. 설명에는 어떤 요청에서 이 스킬을 사용할지 명시하고, 본문에는 수행 순서와 완료 조건을 적습니다. 참고 파일과 스크립트는 실제로 필요할 때 추가합니다.

현재 배포하는 스킬은 다음과 같습니다.

| 스킬 | 하는 일 |
| --- | --- |
| `setup-view` | 저장소를 VIEW 프로젝트에 연결합니다. 이슈 트래커를 VIEW로 정하고 에이전트 지침에 프로젝트 맥락을 적습니다. 사용자가 직접 불러야 실행되며, setup-matt-pocock-skills보다 먼저 씁니다. |

Codex와 Claude Code가 같은 `skills/` 원본을 사용합니다. 스킬을 추가하거나 바꾸면 플러그인 버전도 함께 올리고 두 클라이언트에서 확인합니다.

이 저장소는 공개 배포용입니다. 고객·구성원의 실제 데이터, 자격 증명, 기밀 업무 지침은 포함하지 않습니다.
